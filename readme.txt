当然作者也没太多优化调试，本是考虑到能白嫖阿里云送的免费额度才加的全阿里云模型选项供白嫖党使用，全阿里云模型选项APIKEY选项配置aliyun即可，ds可不管

不要重复训练，阿里云最多30个角色音色，每次点击训练都会添加，删除方法可问ai，作者不想写（后期可能会维护，升级，优化这方面和项目，这得看用户数量了,没人用当然更新缓慢）

退出程序在右小角小图标后台里


警告⚠️：禁止将自己文件夹打包发给别人等导致APIKEY泄露情况概不负责，如有泄露去平台删除自己的APIKEY即可


使用说明：

使用打包的zip文件：解压点击exe文件即可启动，进入后先去设置配置APIKEY，再去点击训练音色系统内置有训练文件能自动完成，查询到了既配置完成，可以开始使用

使用源码：没有提交依赖环境，需要自己装一下，作者使用的pycharm，内含整个项目的markdown开发文件，如果有想法自己改进开发欢迎使用
